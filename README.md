## Installing

1. Open the downloaded `Eco-Print-Technologies-Setup.exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info** and then **Run anyway**.
   The app is safe; this message appears because the installer is not yet code-signed.
3. Follow the steps to choose where to install it.

Requires Windows 10 or 11 (64-bit).
